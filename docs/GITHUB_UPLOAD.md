# GitHub'a Tarayıcı Üzerinden Yükleme

Terminal kullanılmayacaktır.

Ana ve güncel talimatlar repository kökündeki:

```text
BROWSER_ONLY_KURULUM.md
```

dosyasında, **BÖLÜM 1 — GitHub'a kodları yükleme** başlığı altında yer almaktadır.

GitHub tarayıcı yüklemesinde tek seferde en fazla 100 dosya sınırı bulunduğu için hazırlanan üç yükleme parçasını sırasıyla kullanın:

1. `01_GITHUB_ROOT`
2. `02_GITHUB_SRC_APP_COMPONENTS`
3. `03_GITHUB_SRC_OTHER`

Repository'yi `Private` oluşturun ve hiçbir gizli anahtarı GitHub'a yazmayın.
