# Vercel Tarayıcı Kurulumu

Terminal kullanılmayacaktır.

Ana ve güncel talimatlar repository kökündeki:

```text
BROWSER_ONLY_KURULUM.md
```

dosyasında, **BÖLÜM 3 — Vercel kurulumu** başlığı altında yer almaktadır.

Özet:

1. **Add New → Project**
2. GitHub'daki `sdkongre-web` repository'sini seçin.
3. Framework: Next.js
4. Root Directory: `./`
5. Environment Variables değerlerini ekleyin.
6. Deploy düğmesine basın.
7. Değer değiştirdiğinizde Deployments ekranından Redeploy yapın.

Hobby hesaplarında saatlik Cron deployment hatasına yol açabildiği için `vercel.json` günlük çalışacak şekilde hazırlanmıştır.
