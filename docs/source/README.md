# Kaynak Dokümanlar

Bu klasörde kullanıcı tarafından sağlanan kaynak dokümanlar referans ve izlenebilirlik amacıyla tutulmaktadır.

Kod içindeki kurumsal, hizmet, süreç ve yasal metinler bu kaynaklardan yapılandırılmıştır.

Canlı yayın öncesinde:

- Kaynak iddialar şirket tarafından doğrulanmalıdır.
- Yasal metinler yetkili hukuk danışmanı veya kurum sorumlusu tarafından kontrol edilmelidir.
- `LOGOLAR.jpeg` production web logosu değildir; vektör ana logo ile değiştirilmelidir.
