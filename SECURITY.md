# Security Policy

Güvenlik açığı bildirimlerini public GitHub issue olarak paylaşmayın.

Kurumsal güvenlik iletişim adresi belirlendiğinde bu dosyaya ekleyin.

## Kapsam

- Next.js public site
- Admin paneli
- Supabase Auth/Postgres/Storage
- Form endpointleri
- Vercel deployment
- Domain ve DNS yapılandırması

## Gizli bilgiler

Repository'ye şu değerleri eklemeyin:

- `.env.local`
- Supabase Service Role
- Database URL/parolası
- Resend API key
- Turnstile secret
- Production kişisel veri exportları
