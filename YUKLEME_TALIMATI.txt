SDKONGRE E2E navigasyon testi düzeltmesi

1. GitHub'da sdkongreorganizasyon-creator/sdorganizasyon deposunu açın.
2. Add file > Upload files seçeneğine tıklayın.
3. Bu paketteki tests klasörünü yükleme alanına sürükleyin.
4. tests/e2e/home.spec.ts dosyasının değiştirilmesini onaylayın.
5. Commit mesajı:
   fix: scope navigation e2e assertions to main menu
6. Commit changes düğmesine tıklayın.

bulunduğu için Playwright seçicisi iki öğeyle eşleşiyordu. Test artık yalnız
aria-label="Ana menü" olan navigasyon alanını kontrol eder.
